## 1. 背景与问题陈述

Windows 自带的音量控制存在两个结构性痛点：

1. **全局静音不精准**：键盘上的静音键只能把整个系统的声音全部关闭，"只想静音正在吵的那一个应用"做不到。
2. **按应用静音路径太深**：右键任务栏音量图标 → 打开音量合成器 → 找到目标应用 → 点击静音，至少 4 步鼠标操作，在"需要立刻安静"的场景下根本来不及。

现有竞品（EarTrumpet 等）解决了"增强音量合成器"的问题，但交互模型仍是"打开面板再操作"。本产品只做一件事并做到极致：**把"静音当前焦点应用"压缩为一次按键**。

## 2. 产品定位与目标

**一句话定位**：常驻系统托盘、一键开关"当前焦点应用"音量的极致轻量 Windows 工具。

产品设计三原则：

- **轻**：单文件绿色免安装；常驻内存 ≤ 5MB；空闲 CPU 占用为 0（纯事件驱动，无轮询）。
- **静**：默认零打扰，仅操作后给一次轻量反馈（可关闭）。
- **快**：任意场景一键完成静音/恢复，全程不弹出主界面。

可量化目标：

| 指标             | 目标值                     |
| ---------------- | -------------------------- |
| 程序体积         | 单文件 ≤ 5MB（目标 ≤ 2MB） |
| 常驻内存         | ≤ 5MB                      |
| 空闲 CPU         | ≈ 0%                       |
| 冷启动到托盘就绪 | ≤ 300ms（目标 ≤ 200ms）    |
| 静音/恢复响应    | ≤ 50ms                     |
| 安装方式         | 免安装绿色版（可选安装包） |

## 3. 目标用户与典型场景

| 用户画像   | 场景                          | 现有痛点               | EasyMute 解法                  |
| ---------- | ----------------------------- | ---------------------- | ------------------------------ |
| 办公白领   | 上班看视频，老板/同事突然靠近 | 找音量合成器来不及     | 一键静音浏览器                 |
| 游戏玩家   | 游戏过程中语音/网页突然出声   | 切窗口找静音会"送人头" | 游戏中盲按快捷键静音目标应用   |
| 会议/直播  | 共享屏幕时某应用突发声音      | 手忙脚乱且操作被看见   | 快捷键静音，屏幕无任何窗口弹出 |
| 多任务用户 | 浏览器多标签、多应用同时发声  | 无法快速区分与操作     | 静音"当前焦点"的那一个应用     |

## 4. 名词定义

| 名词     | 定义                                                    |
| -------- | ------------------------------------------------------- |
| 焦点应用 | 当前前台窗口所属进程（含其子进程 / 同可执行文件进程群） |
| 音频会话 | 音量合成器中每个应用对应的条目（WASAPI Audio Session）  |
| 静音开关 | 将目标应用的全部音频会话 `IsMuted` 状态取反             |

## 5. 功能需求

### F1 托盘常驻（P0）

- 双击 exe 后**无主窗口、无控制台黑框**，直接以图标形式常驻系统托盘（默认位于右下角折叠隐藏区，用户可自行在系统设置中固定到任务栏）。
- 托盘图标右键菜单：
  - **设置…** —— 打开独立的设置窗口；
  - **退出** —— 注销快捷键、清理托盘图标后完全退出。
- 双击托盘图标 = 打开设置窗口（符合 Windows 惯例）。
- 资源管理器（explorer.exe）重启后，图标自动重新注册恢复。

### F2 全局快捷键：开关焦点应用音量（P0）★核心功能

- 焦点位于**任意窗口**（含桌面、全屏游戏）时，按下快捷键，将"当前焦点应用"的静音状态取反：
  - 当前未静音 → 静音；
  - 当前已静音 → 恢复。
- 快捷键规则：
  - 支持**组合键**：Ctrl / Alt / Shift / Win 任意组合 + 任意键；
  - 支持**单键**：仅限低冲突按键（F1–F24、Pause/Break、ScrollLock）；字母、数字、空格、Enter、Tab 等高频输入键**禁止单独使用**（避免该键在全系统失效，属保护性限制）；
  - 默认快捷键：`Ctrl + Alt + M`。
- 冲突处理：快捷键已被其他程序占用时，注册失败并气泡提示"快捷键被占用，请更换"，**保留原有可用配置**，不得出现"改崩"。
- 无音频会话（焦点应用当前没有创建音频会话）时：气泡提示"当前应用没有音频输出"，不做其他动作。
- 多会话应用（如浏览器多进程各自产生会话）：全部会话统一取反，保证"要么全静、要么全响"。
- 反馈：操作成功后气泡提示"已静音：chrome.exe" / "已恢复：chrome.exe"，可在设置中关闭。

### F3 设置窗口（P0）

- 从托盘菜单"设置…"打开**独立小窗口**（约 360×220 逻辑像素），非模态。
- 窗口内容：
  1. **静音快捷键**：显示当前快捷键（如 `Ctrl + Alt + M`）；点击录入框后按下新组合键即完成采集（Esc 取消，Backspace 清除）；提供"恢复默认"。
  2. **开机自动启动**：勾选框，即时生效。
  3. **操作后显示气泡提示**：勾选框，即时生效。
  4. 版本号信息。
- 保存策略：改动即时生效并落盘（无需"保存"按钮，降低认知负担）；关闭窗口 = 隐藏，程序继续驻留。
- 输入非法/被占用的快捷键时给出即时错误提示且不生效。

### F4 开机自动启动（P0）

- 勾选后在当前用户注册表启动项（`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`）写入自身路径；取消勾选则删除。
- 全程无需管理员权限。
- 静默启动：自启拉起后直接驻留托盘，不弹任何窗口。
- **路径自愈**：若程序被移动位置，每次启动时若自启为开启状态，自动刷新注册表中的路径。

### F5 退出（P0）

- 托盘菜单"退出"：注销全局快捷键 → 移除托盘图标 → 正常结束进程，无残留。
- 退出后按快捷键不应有任何响应。

### F6 单实例（P0）

- 重复双击 exe 不产生第二个进程；已有实例运行时，新实例**唤起已有实例的设置窗口**后自行退出。

### F7 近期迭代（P1）

- 静音状态记忆（记忆每个应用的静音/恢复偏好）；
- 界面语言：简体中文 / English；
- 更多反馈形式（可选屏幕角落 OSD 提示）。

### F8 远期规划（P2）

- 音量大小调节（不限于 0/100）；
- 多快捷键（为不同应用绑定不同快捷键，如"一键静音微信"）；
- 按住 = 静音、松开 = 恢复（Push-to-Talk 式）；
- 指定应用黑白名单（只允许静音白名单内应用）。

## 6. 非功能需求

| 类别   | 要求                                                                       |
| ------ | -------------------------------------------------------------------------- |
| 性能   | 常驻内存 ≤ 5MB；空闲 CPU ≈ 0%；按键响应 ≤ 50ms；无后台轮询                 |
| 体积   | 单文件 exe ≤ 5MB（目标 ≤ 2MB），免安装                                     |
| 兼容   | Windows 10 1809+、Windows 11（x64）；为 ARM64 预留构建能力                 |
| 权限   | 默认普通用户权限即可完成全部功能；不强制申请管理员                         |
| 安全   | 不注入其他进程、不安装键盘钩子（降低杀软误报）；不联网；不收集任何用户数据 |
| 数据   | 配置存放于 `%APPDATA%\EasyMute\`（随用户目录迁移）；卸载即删               |
| 稳定性 | 连续运行 72 小时无内存增长；资源管理器重启、音频设备热插拔后功能自恢复     |
| 高 DPI | Per-Monitor V2 DPI 感知，多显示器下托盘与窗口不模糊                        |
| 本地化 | 中文文案为默认语言，结构上支持国际化                                       |
| 分发   | 绿色单文件为主；可选 Inno Setup 安装包（可选创建开始菜单项）               |

## 8. 验收标准（摘要）

- [ ] 空系统双击 exe：无黑框、无窗口，托盘出现图标；
- [ ] 播放浏览器视频 → 按默认快捷键 → 视频无声（音量合成器中该应用显示为静音）；
- [ ] 再按一次 → 声音恢复；
- [ ] 焦点切到微信/音乐播放器，重复上述两步均生效；
- [ ] 设置中改成 `Ctrl + Shift + F9` 后立即生效；重启程序后配置保留；
- [ ] 试图录入已被占用的快捷键 → 提示且旧快捷键仍可用；
- [ ] 勾选开机自启 → 重启系统 → 自动驻留托盘且原快捷键可用；
- [ ] 右键托盘"退出" → 进程消失、快捷键失效、托盘无残留图标；
- [ ] 任务管理器内存占用 ≤ 5MB；
- [ ] 高分屏（150% 缩放）下图标与文字清晰不模糊。

## 10. 范围外（本期不做）

- 音量数值调节、音频设备切换、音效增强；
- 系统级音频路由（如把某应用声音导到另一设备）；
- 移动端 / macOS / Linux 版本；
- 云同步配置、账号体系。
